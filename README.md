https://marketplace.visualstudio.com/_apis/public/gallery/publishers/{publisher}/vsextensions/{extensionName}/{version}/vspackage?targetPlatform={platform}
• publisher: The publisher ID (e.g., ms-python).
• extensionName: The extension ID (e.g., python).
• version: The exact version string (e.g., 2024.17.2024100401).
• targetPlatform: Optional target OS build (e.g., win32-x64, linux-x64, darwin-arm64).
